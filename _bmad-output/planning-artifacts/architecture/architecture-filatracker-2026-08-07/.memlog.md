- (decision) Merge is a persisted, rebuildable projection with a stable surrogate identity; Offer is the source fact and only the matching module may mutate Merge membership. Binds schema, routes, reprocessing, and search reads; prevents route churn and competing merge ownership.
- (decision) Deploy as two Workers from one modular codebase: web owns SSR/read API/outbound redirect; ingest owns scheduled and queue handlers plus store access. Both consume shared domain/application modules and D1 contracts. Binds runtime permissions and failure domains; prevents scraping failures or credentials from contaminating public request handling.
- (decision) Each Store adapter is a schema-validated declarative map plus optional typed discovery/extraction hooks; it emits RawOfferObservation only. Shared pipeline stages exclusively own normalization, validation, matching, history, and persistence. Binds adapter contract and homologation fixtures; prevents per-store business-rule forks and runtime self-repair.
- (decision) Ingestion publishes atomically per Store run: observations stage under a run identity, validation gates promotion, and only a successful promotion may update availability or append changed price history. Failed or partial runs preserve the prior published snapshot. Binds mutation and idempotency; prevents parser failures, retries, or partial runs from mass-marking Offers unavailable or duplicating history.
- (decision) Search uses a rebuildable D1 FTS5 projection over normalized text. FTS returns stable Merge or Offer identities; relational published tables remain authoritative for availability, price, filters, and ranking. Binds search indexing and query ownership; prevents search index data from becoming transactional truth or an external dual-write system.
- (version) Cloudflare D1 FTS5 support verified from official D1 SQL documentation updated 2026-04-21; virtual tables are excluded from D1 exports and must be recreated from relational source data.
- (decision) D1 access uses Drizzle at persistence adapters with generated, versioned SQL migrations applied by Wrangler; FTS5 and atomic publication may use reviewed explicit SQL.
